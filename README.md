# 📊 Credit Risk Analysis using PaisaBazaar Dataset

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on a credit risk dataset to identify customer financial behavior, understand factors influencing credit scores, and generate business insights using Python and Tableau.

The analysis focuses on understanding customer income, credit utilization, payment behavior, occupation, and other financial indicators to support better credit risk assessment.

---

## 🎯 Business Objective

The objective of this project is to:

- Analyze customer financial profiles.
- Understand factors affecting credit scores.
- Discover patterns in payment behavior.
- Generate business insights through data visualization.
- Build an interactive Tableau dashboard for decision-making.

## 📌 Key Insights

- Customers with Good Credit Scores generally maintain lower credit utilization.
- Annual income alone does not guarantee a higher credit score.
- Payment behaviour is strongly associated with customer credit scores.
- Credit utilization ratio plays a significant role in identifying potential credit risk.
